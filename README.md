# 4S Scoring

Swing · Stick · Sink · Score — golf league scoring: live gross/net leaderboards by flight, group score entry, card check, bumps per hole, deuce pot, gross/net skins and payouts. Net math matches Golf Genius (exact course handicap to one decimal).

Static site (GitHub Pages) + Supabase for data. Math lives in `calc.js`; run `node test/calc.test.mjs`.
